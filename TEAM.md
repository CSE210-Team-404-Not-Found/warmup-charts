# Team Roster

Please add yourself to this document so we know who you are, and a little bit about you!

## How to Add Yourself
1. Create a branch named after you:
```sh
git checkout main
git pull
git checkout -b <your-name>
```
2. Add your entry to the **Members** list below, in the format: `**Name** (Subteam): A short description of yourself`.
3. Commit and push your branch:
```sh
git add TEAM.md
git commit -m "Add <your-name> to TEAM.md"
git push -u origin <your-name>
```
4. Open a pull request into `main` on Github.

I presume we are all familiar with `git` at this point. If you need further guidance, please reach out.
