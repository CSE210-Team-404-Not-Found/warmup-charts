parseCSV(text, optionsopt) → {Array.<Series>}

Parse CSV text into series.

Format (wide layout, plain commas with no quoting; see docs/decisions/0010-csv-input-format.md):

x,Revenue,Cost
0,1.2,0.8
1,1.5,

The header row is comprised of x, followed by each series in the file in order.

An empty data column means a series has no point at that x.

Non-numeric cells must be skipped. If x is non-numeric, the entire row must be skipped.

If the header is missing, there are fewer than two columns, or duplicate names exist, the function must throw.
