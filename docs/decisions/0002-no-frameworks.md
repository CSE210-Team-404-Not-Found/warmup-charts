# ADR-0002: Use plain HTML, CSS, and JavaScript with no frameworks

## Considered Options

* Plain HTML/CSS/JavaScript
* A framework such as React

## Decision Outcome

Chosen option: **plain HTML/CSS/JavaScript**, because the project's
requirements do not justify a framework.

### Consequences

* Good: no build step is required.
