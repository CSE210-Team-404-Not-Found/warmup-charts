# ADR-0005: Project scope

## Decision Outcome

MVP:

* Points and lines
* Plotted data
* Axis labels
* Fixed axis start and end values
* Multiple data series with distinct colors, likely including a legend.
  Adopted as a unit, since multiple series without distinct colors would be
  hard to tell apart.

Stretch goals:

* Hover interactions
* Configurable axis start and end values
* X-axis markers for significant events
