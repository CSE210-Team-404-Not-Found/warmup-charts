Class: RenderScheduler

RenderScheduler()

Manage the workers and data chunks for one chart's scatter renderer.

Each worker keeps its own transferred point data and OffscreenCanvas, while the chart controls when the resulting bitmap layers are composited.

Constructor

new RenderScheduler()

Start a bounded pool, leaving at least one reported core for the page.
